Модуль 1: Введение в систему HUB

Теория

HUB — это система для управления складскими предметами и процессами их перемещения, хранения и инвентаризации.

Ключевые понятия:

  • Предмет: Объект хранения (например, коробка, отправление).
  • Логистический контейнер (ЛК): Емкость для хранения/перемещения предметов.
  • Инвентаризация: Проверка фактического наличия предметов на складе.
  • КМО: Документация о материальных ошибках.
  • ЦМН: Цель доставки.
  • Тайм-слот: Временной интервал для доставки.

Модуль 2: Основы интерфейса HUB и карточка предмета

Теория

Интерфейс HUB включает главное меню, схему склада и таблицу предметов. Карточка предмета — детализированное окно с информацией о конкретном объекте.

Структура карточки предмета:

Вкладка Описание
«О предмете» Основная информация о предмете.
«Состав» Текущий и исторический состав контейнера.
«История (перемещения)» История перемещений предмета.
«Отгрузки» Запись о выдаче предмета со склада.
«Транспорт» История взаимодействия с транспортными средствами.
«История свойств» Изменения свойств предмета.

Практика

Задание: Найдите предмет с ID "BOX-456" и изучите вкладку «О предмете».

Модуль 3: Поиск предметов в HUB

Теория

Чтобы найти предмет:

  1. Нажмите значок «лупы» (🔍) или сочетание клавиш «Ctrl+I».
  2. Введите идентификатор (ID, SCAN-IT, ШК этикетки).
  3. Система выведет список найденных предметов.

Практика

Задание: Найдите предмет с ID "GR-00123" и откройте его карточку.

Модуль 4: Работа с вкладками карточки предмета

Теория

Каждая вкладка карточки предмета предоставляет уникальную информацию:

  • «О предмете»: Основные данные (тип, статус, ID, номенклатура).
  • «Состав»: Список предметов внутри контейнера.
  • «История (перемещения)»: История перемещений предмета.
  • «Отгрузки»: Информация о выдаче предмета со склада.
  • «Транспорт»: История взаимодействия с транспортными средствами.
  • «История свойств»: Изменения свойств предмета.

Практика

Задание: Откройте вкладку «Состав» для контейнера "LC-777" и изучите его текущий состав.

Модуль 5: Пересчеты и инвентаризации в HUB

Теория

Для запуска пересчета:

  1. Выберите зону на схеме склада.
  2. Нажмите «Запустить пересчет».
  3. Просмотрите детали пересчета: фактический список, балансовый список, излишки, недостачи.

Практика

Задание: Запустите пересчет для ячейки "B-42" и проанализируйте результаты.

Модуль 6: Работа с логистическими контейнерами

Теория

Для формирования контейнера:

  1. Найдите контейнер и нажмите «Сформировать».
  2. Убедитесь, что контейнер соответствует условиям, и отмените формирование.

Практика

Задание: Найдите контейнер "LC-999" и сформируйте его.
